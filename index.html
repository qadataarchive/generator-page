🛠️ 웹 폼 & Apps Script 통합 생성기

① 기본 설정

📌 확인 방법: 구글 드라이브에서 사진 폴더를 열고, 주소창 drive.google.com/drive/folders/이 부분을 복사합니다.
📌 확인 방법: 시트 [확장 프로그램] > [Apps Script]에 코드를 넣고 [배포] > [새 배포] > 유형 "웹 앱"으로 배포하면 발급되는 주소(/exec로 끝남)입니다.

② 질문 설정

질문 순서대로 시트 열이 배정됩니다. 소제목(구분)은 열을 차지하지 않습니다. 질문을 추가·삭제·순서변경 하면 반드시 전체 생성을 다시 누르고, 새로 나온 웹 HTML과 Apps Script를 함께 교체하세요.

[전체 코드 및 설명서 생성하기]를 누르면 설정에 맞춘 설명서가 여기에 표시됩니다.
