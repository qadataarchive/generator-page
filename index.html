🛠️ Web Form & Apps Script 통합 생성기 (최종 완성본)

💡 Folder ID란? 첨부파일이 저장될 구글 드라이브 폴더의 고유 식별자입니다.
📌 확인 방법: 구글 드라이브에서 해당 폴더에 들어간 뒤, 웹 브라우저 주소창 URL의 맨 뒤 값(drive.google.com/drive/folders/이부분)을 복사해 붙여넣으세요.
💡 Web App URL이란? 웹 폼 제출 데이터를 스프레드시트로 전송해 주는 서버 주소입니다.
📌 확인 방법: 구글 시트 상단 메뉴 [확장 프로그램] > [Apps Script]에서 코드를 넣은 후, 오른쪽 상단 [배포] > [새 배포]를 완료하면 발급되는 URL입니다.

질문 항목 설정



[전체 코드 및 설명서 생성하기] 버튼을 누르면 설정된 질문 개수에 맞춘 동적 열 가이드가 여기에 출력됩니다.
